TurtleGUI Web Application Demo

This demo showcases a layered approach to GUI design with multiple anchored panels:

  • Top Menu: Anchored to the top of the screen
  • Side Menu: Anchored to the left side
  • Main Content: Fills the remaining space
  • Notifications: Appear at the bottom right
  • Modal Dialogs: Center-screen popups with backdrop

Click the options in the left menu to see notifications and dialogs in action.

Features Demonstrated

  • CSS-based layered layout system
  • Custom animations using gui-onshow and gui-onhide
  • Modal dialogs with semi-transparent backdrop
  • Auto-dismissing notifications
  • Interactive menu system
